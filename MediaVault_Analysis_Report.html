增加 **全局搜索**（顶部搜索栏或长按 Tab 弹出）：可以同时搜索黑胶和影视。

2.2 体验增强功能（P1）中优先级

3.3 数据库 Schema 扩展建议

-- 列表/片单功能
CREATE TABLE lists (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  description TEXT,
  type TEXT NOT NULL, -- 'vinyl' | 'movie' | 'mixed'
  cover_url TEXT,
  is_public INTEGER DEFAULT 0,
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE list_items (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  list_id INTEGER NOT NULL,
  item_type TEXT NOT NULL, -- 'vinyl' | 'movie'
  item_id INTEGER NOT NULL,
  sort_order INTEGER DEFAULT 0,
  note TEXT,
  FOREIGN KEY (list_id) REFERENCES lists(id)
);

-- 价格追踪
CREATE TABLE price_history (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  vinyl_id INTEGER NOT NULL,
  marketplace TEXT, -- 'discogs', 'ebay'
  price REAL,
  currency TEXT DEFAULT 'USD',
  recorded_at TEXT DEFAULT CURRENT_TIMESTAMP
);

-- 流媒体平台信息
CREATE TABLE watch_providers (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  movie_id INTEGER NOT NULL,
  country_code TEXT NOT NULL,
  provider_name TEXT,
  provider_type TEXT, -- 'flatrate', 'rent', 'buy'
  logo_path TEXT,
  updated_at TEXT DEFAULT CURRENT_TIMESTAMP
);

4. 社交元素评估

结论：初期不建议加入完整社交功能，但可设计"轻社交"元素。

阶段 社交策略 理由
V1.0 无社交，纯个人工具 专注核心体验打磨，降低复杂度
V1.5 分享功能（生成海报卡片） 用户可以分享到社交媒体，低成本获客
V2.0 关注 + 动态 有用户基础后考虑
V3.0 社区 + 小组 需要运营投入

V1.5 推荐的轻社交方案：

  • 分享卡片生成：自动生成精美的封面+评分+一句话推荐的图片，可分享到朋友圈/微博
  • 年度回顾分享：参考 Spotify Wrapped，生成可分享的年度统计卡片
  • 导入导出：支持导出为 Letterboxd/Discogs 兼容格式，方便与其他平台用户交流

3. 数据安全与隐私合规

3.1 API Key 暴露风险

当前风险评估：

tr>
API Key 存储方式 风险等级 说明
DISCOGS_TOKEN 环境变量 → Expo Constants ⚠️ 中 编译后嵌入 JS Bundle，可被反编译提取
TMDB_API_KEY 环境变量 → Expo Constants ⚠️ 中 同上
NOTION_API_KEY 环境变量 → Expo Constants 🔴 高 写权限，风险更大

缓解方案：

方案 说明 推荐度
后端代理 创建轻量后端（Cloudflare Workers / Vercel Edge），App 请求后端，后端调用 API ⭐⭐⭐ 最佳
Key 限制 Discogs: 设置 Rate Limit；TMDB: API Read Access Token（有限权限） ⭐⭐ 必做
定期轮换 设置提醒定期更换 API Key ⭐⭐
Notion 分离 Notion API Key 单独管理，不打包进 App，用户自行配置 ⭐⭐⭐ 推荐

建议优先级：

  1. 短期（V1.0）：使用 TMDB Read Access Token（而非 API Key），Discogs Token 设置 IP 白名单
  2. 中期（V1.5）：搭建 Cloudflare Workers 代理，App 不再直接暴露 Key
  3. Notion：改为用户自行配置，提供设置页面输入 API Key

3.2 本地数据安全

风险 现状 建议
SQLite 明文存储 ✅ 符合个人收藏 App 预期 可考虑 expo-sqlite 的 SQLCipher 支持（加密数据库）
备份风险 iOS 自动备份到 iCloud 确保 expo-file-system 的备份排除配置
Notion 同步 数据传输到第三方 隐私政策中说明
